What happens when you drop a file

Every stage is generic — the same code path runs for a housing dataset, a passenger manifest, or a retail sales log. The only thing that changes is what the data tells it to do.

Upload

CSV or Excel, read straight into a dataframe — no size limit beyond your own RAM.

Schema inference

Every column is classified: numeric, categorical, datetime, geospatial, text, identifier.

Cleaning

Median/mode imputation, skew correction, per the profile — not hardcoded per dataset.

Feature engineering

One-hot / frequency encoding, calendar expansion, geospatial clustering — role-driven.

Model comparison

5 regressors or 3 classifiers trained on an identical split; best one wins automatically.

Diagnostics

VIF pruning, Breusch-Pagan, Q-Q and residual plots — plus ACF/stationarity for dates.

Report

A full HTML report, rendered right here — the exact same template the CLI writes to disk.

Why this is a real engine, not a demo mockup

This page loads the identical tabular_autopilot Python package used by the CLI and the Streamlit app — packaged as a wheel and installed at runtime via Pyodide's micropip.

Same code, three interfaces

CLI, Streamlit app, and this browser demo all call the exact same run_pipeline() — no separate "demo" logic to drift out of sync.

Genuinely private

There is no backend for this page to call. Your data is parsed and modeled by WebAssembly running in this tab, and discarded when you close it.

Honest about scale

Datasets over 5,000 rows are sampled down for this in-browser demo to stay responsive — the CLI and Streamlit app run the full dataset.
